# Advanced Database Systems Portfolio (MIT 8103)

Individual practical portfolio for **MIT 8103 Advanced Database Systems**,
2026/2027 Academic Session, Master of Information Technology,
MIVA Open University.

## Case Study
**LendDesk** (a simulated organisation): a multi-tenant loan management SaaS
platform. This portfolio focuses on its **user and access management
database**: organisations, users, roles, permissions and user activity logs.

All data is simulated. No real company, employee or customer data is used.

Full details: [case-study.md](portfolio-1-database-design/case-study.md)
